## 2. 运行环境配置 (Environment Setup)

为确保程序可完全跑通且不因版本冲突产生异常，建议在 **Python 3.9 至 Python 3.11** 之间构建独立的虚拟环境（如 Anaconda）。

### 2.1 核心依赖库列表
本程序主要依赖以下开源科学计算、非线性动力学分析及机器学习库：
* `wfdb` (v4.1.2+) ：用于读取和解析 PhysioNet 原始心电信号及 `.qrs` 注解文件。
* `hrvanalysis` (v1.0.4) ：用于提取心率变异性（HRV）指标、识别并剔除异位搏动（Ectopic Beats）。
* `pyrqa` (v0.1.0+) ：基于 OpenCL 加速的定量递归分析（RQA）库，用于构建递归图并计算局部动力学指标。
* `networkx` (v3.1+) ：用于将递归矩阵转换为拓扑网络，并计算平均度、聚类系数等全局特征。
* `xgboost` (v2.0.0+) ：极端梯度提升树分类器，用于对融合特征进行高性能训练与集成学习预测。
* `scikit-learn` (v1.3.0+) ：提供数据集划分、混淆矩阵计算及分类性能评估接口。
* `numpy` (v1.24.3), `pandas` (v2.0.3), `scipy`, `matplotlib`, `tqdm`

项目根目录下已附带 `requirements.txt` 文件。请在终端（Terminal）或 Anaconda Prompt 中切换至项目根目录，执行以下命令完成一键配置：

## 5. 详细运行流程与复现指南

评卷老师可按照以下步骤依次打开并运行 Jupyter Notebook。程序中所有核心逻辑（如数据清洗、矩阵转换、特征值分解、分类器训练）均包含详尽的**中文行内注释**。

### 步骤一：运行定量递归分析预测 (`RQN.ipynb`)

1. 启动 Jupyter Notebook 或 JupyterLab，打开 `RQN.ipynb`。
2. 依次点击菜单栏的 `Kernel` -> `Restart & Run All`（或逐个 Cell 执行）。
3. **程序内部执行逻辑**：
* **Cell 1-2**：导入依赖项，并从原始 Holter 心电图数据中提取并清洗远离房颤段（NSR）和紧邻房颤发作前段（Pre-AF）的 5 分钟 RR 间期序列，随后自动将清洗后的数组存入 `pro_data/` 目录。
* **Cell 3**：利用重构空间参数（维度 $m=3$，延迟 $\tau=2$）构建 `TimeSeries`，编写 RQA 局部特征提取通用函数。
* **Cell 4**：以确定度（DET）指标为例，程序将遍历 $0.01 \sim 0.20$ 的距离阈值区间，利用 `tqdm` 打印寻优进度条，自动寻找令 XGBoost 分类准确率达到最优的距离阈值。
* **Cell 5**：使用最佳阈值在测试集上进行预测，并打印包含精确率、灵敏度（Recall）和 F1-score 的最终分类报告。


4. **预期运行表现**：控制台将完整打印出最优阈值搜索过程，并输出单度量下对应的准确率（约 0.70 - 0.73），结果与报告中“5.2 定量递归分析度量预测分析”章节中的数据完全契合。

### 步骤二：运行递归复杂网络与特征融合预测 (`RCN.ipynb`)

1. 打开 `RCN.ipynb`。
2. 选择 `Restart & Run All` 一键执行。
3. **程序内部执行逻辑**：
* **Cell 1-3**：导入复杂网络及谱分析核心库，定义基于高级规则（如剔除异常起搏、线性与非线性双向插值）的信号精细化清洗函数。
* **Cell 4**：核心函数 `get_rqa_all` 实现将重构的二值化递归矩阵转换为 `NetworkX` 的邻接矩阵结构。一方面计算网络的平均度、平均聚类系数；另一方面调用自定义的 `compute_kth_moment` 求解邻接矩阵特征值，推导密度谱的三阶矩。最后，将 RCN 的 3 维全局拓扑特征与 RQA 的 4 维局部微观特征水平拼接，融合成一个 7 维的高维特征向量。
* **Cell 5**：将融合特征矩阵输入 XGBoost 分类器，进行训练与测试集 8:2 划分验证，并打印最终分类报告。


4. **预期运行表现**：程序运行结束后，控制台会输出特征融合后的模型综合性能，包括灵敏度（Sensitivity）、特异度（Specificity）以及总准确率（Accuracy），准确率将直接达到 **0.86** 左右，与报告“5.4 特征融合”部分的表4-3完全保持一致。

## 7. 异常处理与注意事项

1. **显存/显卡驱动报错**：`pyrqa` 在某些特定平台上可能会因 OpenCL 平台选择错误而提示警告，代码中已通过设置 `verbose=False` 进行了抑制，该警告不影响矩阵的正常计算与最终特征提取。
2. **数据未找到**：如果程序在第一步提示 `FileNotFoundError`，请仔细核对第3节中所述的官方数据库文件夹名称是否带有版本号后缀（`.1.0.0`），且是否放置在与 `.ipynb` 同级的根目录下。
3. **中文显示问题**：代码中已加入 `plt.rcParams['font.sans-serif'] = ['AR PL UKai CN']`（或默认的中文字体支持），确保在 Linux 和 Windows 系统下生成度分布直方图和箱线图时，坐标轴中的中文“度”、“概率”能够正常渲染。
